# Modos operacionais

## 1. Ambient Mode

Estado normal.

- presença discreta;
- monitorização leve;
- poucas interrupções;
- mundo vivo;
- alertas apenas relevantes.

## 2. Focus Mode

- uma missão;
- notificações reduzidas;
- agentes limitados;
- cronómetro;
- bloqueios visíveis;
- check-ins mínimos.

## 3. War Room

Para decisões e operações críticas.

Mostra:

- objetivos;
- bloqueios;
- agentes;
- Money Machine;
- riscos;
- prazos;
- métricas;
- decisões pendentes.

O Oráculo fala de forma curta e operacional.

## 4. Strategy Mode

Para pensar.

- cenários;
- trade-offs;
- riscos;
- hipóteses;
- perguntas;
- simulações;
- decisões.

## 5. Debrief Mode

- acontecimentos;
- resultados;
- falhas;
- aprendizagem;
- amanhã;
- memória proposta.

## 6. Briefing Mode

- prioridades;
- agenda;
- estado;
- riscos;
- oportunidades;
- recomendações.

## 7. Recovery Mode

Quando existe sobrecarga, falha ou exaustão.

- reduz escopo;
- prioriza segurança;
- suspende tarefas não essenciais;
- evita culpa;
- constrói recuperação.

## 8. Money Machine Mode

- pipeline;
- leads;
- ofertas;
- follow-ups;
- entregas;
- receita;
- agentes;
- custos.

## 9. Silent Mode

- sem voz;
- sem interrupções;
- apenas eventos críticos;
- registo silencioso.

## 10. Maintenance Mode

- agentes pausados;
- workflows limitados;
- diagnóstico;
- migrações;
- validação;
- sem ações externas.

## Transição

Entrar num modo deve:

- mostrar o modo;
- explicar alterações;
- preservar saída;
- permitir sair rapidamente.
