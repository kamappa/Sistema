# Autonomia e modelo de aprovação

## Princípio

A autonomia cresce por níveis.

Não existe autonomia total por defeito.

## Nível 0 — Observação

Pode:

- ler;
- resumir;
- detetar;
- organizar.

Não pode executar.

## Nível 1 — Preparação

Pode:

- criar rascunhos;
- preparar planos;
- criar tarefas pendentes;
- sugerir workflows;
- montar pacotes de contexto.

Requer aprovação para executar.

## Nível 2 — Execução reversível

Pode executar ações de baixo risco previamente autorizadas:

- etiquetar;
- organizar;
- atualizar estados internos;
- reagendar dentro de limites;
- iniciar pesquisas;
- criar drafts.

## Nível 3 — Execução condicionada

Pode executar ações externas dentro de políticas:

- follow-ups aprovados;
- chamadas de API limitadas;
- movimentação de leads;
- envio de relatórios internos;
- workflows com orçamento baixo.

## Nível 4 — Gestão supervisionada

Pode gerir operações inteiras dentro de limites:

- pipeline de leads;
- investigação recorrente;
- monitorização;
- triagem;
- preparação de propostas;
- auditoria de agentes.

## Nível 5 — Autonomia ampliada

Só no futuro, com:

- histórico forte;
- políticas maduras;
- testes;
- orçamento;
- kill switch;
- auditoria;
- simulação;
- aprovação explícita.

## Matriz de risco

Avaliar:

- impacto;
- reversibilidade;
- custo;
- exposição externa;
- sensibilidade;
- confiança;
- precedentes;
- tempo.

## Ações sempre sujeitas a aprovação

- pagamentos;
- compras;
- contratos;
- publicação pública;
- mensagens sensíveis;
- compromissos legais;
- eliminação permanente;
- alteração de identidade;
- mudança de objetivos;
- decisões médicas;
- acesso a credenciais;
- mudanças de produção críticas.

## Kill switch

Deve existir:

- botão global;
- comando de voz;
- comando textual;
- modo de manutenção;
- pausa por agente;
- pausa por workflow;
- pausa por domínio.

## Regra de escalada

Quando o Oráculo não sabe se pode agir, deve perguntar.

## Aprovação informada

Uma aprovação deve mostrar:

- ação;
- agente;
- motivo;
- dados usados;
- custo;
- risco;
- reversibilidade;
- efeito esperado.
