# Governação de agentes

## Objetivo

Evitar que vários agentes se tornem um conjunto caótico de ferramentas
sobrepostas.

## Registo de agentes

Cada agente deve ter:

- nome;
- função;
- proprietário;
- permissões;
- ferramentas;
- custos;
- limites;
- tipos de tarefa;
- dados acessíveis;
- métricas;
- histórico;
- estado;
- kill switch.

## Delegação

O Oráculo escolhe agente com base em:

- competência;
- risco;
- custo;
- latência;
- contexto;
- taxa de sucesso;
- privacidade;
- disponibilidade.

## Contrato de tarefa

Toda a tarefa delegada deve incluir:

- objetivo;
- contexto mínimo;
- critérios de sucesso;
- prazo;
- orçamento;
- permissões;
- proibições;
- formato de retorno;
- necessidade de aprovação.

## Retorno

O agente deve devolver:

- estado;
- resultado;
- evidência;
- erros;
- custo;
- confiança;
- próximos passos.

## Conflitos

Se dois agentes discordarem:

1. o Oráculo compara evidência;
2. procura fonte adicional;
3. apresenta incerteza;
4. escala quando necessário.

## Reputação de agentes

O Sistema pode medir:

- qualidade;
- taxa de erro;
- custo;
- tempo;
- necessidade de retrabalho;
- cumprimento de políticas.

## Proibição

Nenhum agente pode:

- aumentar as próprias permissões;
- alterar políticas;
- ocultar custos;
- declarar sucesso sem prova;
- delegar indefinidamente;
- criar loops sem limite.
