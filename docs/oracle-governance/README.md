# Oracle Governance Pack V2

## Quatro ficheiros principais

- `SYSTEM-ORACLE-CONSTITUTION.md`
- `CLAUDE-ORACLE-BLOCK.md`
- `SPEC-ORACLE-BLOCK.md`
- `ROADMAP-ORACLE-BLOCK.md`

Estes ficheiros deixaram de ser pequenos apontamentos. Agora definem leis,
processo de trabalho, programa técnico e evolução.

## Ficheiros numerados

A pasta `docs/oracle-governance/` contém os documentos especializados.

Não existe uma pasta numerada separada para cada bloco porque isso duplicaria
regras e criaria contradições.

Os quatro ficheiros principais são entradas de autoridade.

Os ficheiros 00–30 são a documentação detalhada partilhada por todos eles.
