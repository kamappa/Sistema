# Skills e autoaperfeiçoamento

## Skill Registry

Cada skill deve ter:

- nome;
- versão;
- função;
- inputs;
- outputs;
- ferramentas;
- riscos;
- custos;
- testes;
- owner;
- histórico.

## Processo de criação

1. detetar necessidade;
2. demonstrar repetição;
3. propor skill;
4. definir limites;
5. testar;
6. aprovar;
7. ativar;
8. medir;
9. rever.

## Autoaperfeiçoamento permitido

- otimizar prompts;
- melhorar roteamento;
- reduzir custo;
- melhorar contexto;
- melhorar observabilidade;
- propor novos testes.

## Não permitido sem aprovação

- mudar personalidade;
- aumentar permissões;
- mudar políticas;
- alterar Constituição;
- adicionar canais externos;
- ativar execução financeira;
- apagar logs.
