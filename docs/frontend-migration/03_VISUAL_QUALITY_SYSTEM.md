# Sistema de qualidade visual

Tecnologia moderna não garante design moderno.

A qualidade deve ser imposta por processo.

## Pipeline visual obrigatório

1. Capturar baseline.
2. Fazer auditoria no browser real.
3. Identificar o maior problema visual.
4. Criar duas ou três direções.
5. Comparar em desktop e mobile.
6. Escolher uma direção.
7. Implementar apenas uma área.
8. Capturar novo screenshot.
9. Validar performance e acessibilidade.
10. Só aceitar se houver melhoria clara.

## Pergunta obrigatória

Para cada componente:

> Isto parece um produto único chamado Sistema, ou um dashboard gerado por AI?

Se parecer dashboard:

- reduzir borders;
- reduzir grids rígidas;
- rever tipografia;
- criar profundidade;
- melhorar composição;
- retirar ornamentos genéricos;
- usar luz e hierarquia;
- melhorar motion;
- voltar a iterar.

## Assinatura do Sistema

- preto e roxo como base;
- azul profundo;
- magenta subtil;
- serenidade por defeito;
- eventos épicos raros;
- materiais escuros e espaciais;
- hierarquia forte;
- luz seletiva;
- pouco ruído;
- movimento lento;
- nenhum cyberpunk cliché.

## O que as ferramentas podem fazer

### 21st.dev Magic

Pode:

- gerar variações;
- acelerar protótipos;
- criar componentes candidatos;
- explorar layouts.

Não pode:

- definir a identidade;
- substituir o design system;
- introduzir shadcn genérico;
- fazer commit automático sem revisão.

### ui-ux-pro-max

Deve:

- auditar consistência;
- construir a bíblia visual;
- verificar UX;
- avaliar densidade, tipografia, navegação e responsividade.

### Superpowers

Deve:

- decompor problemas;
- criar planos;
- impedir implementação apressada;
- suportar debugging disciplinado;
- manter uma fase de cada vez.

## Critério de força

Um resultado forte é aquele em que:

- a primeira impressão mudou radicalmente;
- a interface tem centro visual;
- a hierarquia é entendida sem esforço;
- não existe dependência de bordas roxas;
- cada painel tem função e personalidade;
- a conta nova não parece vazia;
- o mundo continua vivo em idle;
- o mobile parece produto, não versão encolhida.
