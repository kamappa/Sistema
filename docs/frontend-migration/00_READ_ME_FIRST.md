# Frontend Migration — Read Me First

Esta pasta define a migração da próxima geração visual do Sistema.

Objetivo: transformar a frontend atual numa experiência moderna, premium,
cinematográfica e sustentável sem destruir a lógica, os dados ou a identidade
já construídos.

O Claude Code deve consultar esta pasta antes de qualquer missão que envolva:

- redesign da shell;
- migração de frontend;
- React, TypeScript ou Vite;
- Vercel;
- React Three Fiber;
- criação de novos componentes;
- alteração estrutural do sistema visual;
- substituição da arquitetura atual;
- implementação com Superpowers, ui-ux-pro-max ou 21st.dev Magic.

## Regra central

A migração não existe para “modernizar tecnologia”.

Existe para permitir:

- uma linguagem visual própria;
- componentes consistentes;
- motion físico e coerente;
- testes visuais reais;
- evolução durante anos;
- melhor manutenção;
- previews seguros;
- performance controlada;
- ausência de aparência genérica de dashboard AI.

## Proibição

Não converter tudo de uma vez.

Não apagar a versão estável.

Não alterar produção antes de aprovação.

Não migrar dados ou lógica sem testes de paridade.

Não aceitar componentes gerados automaticamente sem direção artística.

Não introduzir React, TypeScript ou Vite na `main` estável sem branch e plano.
