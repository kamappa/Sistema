# Gates de aceitação

## Gate 1 — Fundação

- build passa;
- lint passa;
- TypeScript sem erros;
- preview Vercel existe;
- Supabase liga;
- nenhuma chave exposta.

## Gate 2 — Visual

- screenshot mudou de forma claramente positiva;
- não parece dashboard AI;
- mobile tem composição própria;
- tipografia consistente;
- menos borders;
- centro visual claro;
- surfaces coerentes.

## Gate 3 — Motion

- reduced motion funciona;
- motion comunica estado;
- nada distrai;
- interações parecem físicas;
- animações não bloqueiam.

## Gate 4 — Performance

- desktop fluido;
- mobile aceitável;
- sem memory leaks;
- tab escondido pausa;
- qualidade adapta;
- sem erros WebGL graves.

## Gate 5 — Dados

- mesmos dados;
- mesmos cálculos;
- XP correto;
- reversão correta;
- auth correta;
- RLS correta;
- sem duplicação.

## Gate 6 — Produção

- preview aprovado;
- testes reais feitos;
- rollback;
- backups;
- domínio;
- variáveis;
- aprovação explícita.

## Critério final

Não basta “funcionar”.

Tem de:

- parecer único;
- parecer moderno;
- parecer intencional;
- estar tecnicamente sustentável;
- preservar a verdade do Sistema.
