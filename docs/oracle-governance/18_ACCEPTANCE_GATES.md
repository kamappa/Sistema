# Gates de aceitação

## Gate de identidade

- parece Oráculo;
- não parece chatbot genérico;
- personalidade consistente;
- fala apenas com valor;
- mantém verdade.

## Gate de voz

- escuta visível;
- cancelamento;
- transcrição;
- confiança;
- confirmação de comandos;
- privacidade;
- barge-in;
- fallback textual.

## Gate de memória

- origem;
- correção;
- remoção;
- confiança;
- separação entre facto e inferência;
- contexto mínimo.

## Gate de autonomia

- política;
- aprovação;
- reversibilidade;
- kill switch;
- logs;
- limites;
- custo;
- escalada.

## Gate de agentes

- função clara;
- permissões;
- contrato;
- output;
- reputação;
- sem loops;
- sem autoelevação.

## Gate Money Machine

- legal;
- ético;
- sem spam;
- aprovação;
- qualidade;
- métricas;
- entrega possível;
- rastreabilidade.

## Gate de confiança

- explica decisões;
- admite erro;
- corrige;
- não inventa;
- distingue confiança.

## Gate operacional

- monitorização;
- recuperação;
- pausa;
- fallback;
- idempotência;
- alertas;
- observabilidade.

## Gate final

O Oráculo só é considerado melhor se:

- poupa tempo;
- reduz caos;
- melhora decisões;
- protege atenção;
- mantém controlo humano;
- aumenta capacidade sem aumentar risco de forma desproporcional.
