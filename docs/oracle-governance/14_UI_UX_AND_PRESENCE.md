# UI, UX e presença do Oráculo

## Princípio

O Oráculo não deve existir apenas numa caixa de chat.

Deve ter presença distribuída e coerente.

## Formas de presença

- voz;
- painel principal;
- command palette;
- indicadores;
- timeline;
- alertas;
- briefing;
- War Room;
- overlays contextuais;
- cartões de decisão;
- activity ledger;
- agent status.

## Centro do Oráculo

Deve mostrar:

- estado;
- foco;
- observações;
- decisões pendentes;
- agentes;
- memória recente;
- notificações;
- capacidade de voz;
- confiança;
- modo atual.

## Representação visual

A presença deve ser:

- subtil;
- viva;
- precisa;
- não antropomórfica por obrigação;
- coerente com o universo;
- reativa a estado real.

## Estados

- idle;
- listening;
- thinking;
- delegating;
- waiting;
- verifying;
- warning;
- blocked;
- speaking;
- silent.

Cada estado deve ser visualmente distinguível.

## Voz e visual

Quando ouve:

- indicador claro;
- waveform discreto;
- transcrição;
- cancelamento.

Quando pensa:

- não fingir progresso;
- mostrar tarefa real;
- mostrar agente envolvido;
- permitir cancelar.

Quando executa:

- ação;
- estado;
- custo;
- resultado.

## Anti-dashboard AI

Evitar:

- chat central como única experiência;
- roxo em todas as bordas;
- cartões genéricos;
- mensagens enormes;
- animações sem função;
- “AI glow” constante;
- ícone de cérebro como identidade.

## Acessibilidade

- teclado;
- contraste;
- reduced motion;
- legendas;
- transcrição;
- controlo de volume;
- feedback não apenas visual;
- estados claros.
