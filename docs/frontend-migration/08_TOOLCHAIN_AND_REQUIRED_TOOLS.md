1. Context7 valida documentação.
2. Superpowers cria plano.
3. ui-ux-pro-max audita UX e design.
4. Magic cria variações quando útil.
5. Claude in Chrome observa.
6. Playwright captura.
7. DevTools valida consola/network/performance.
8. Daniel aprova.
9. Claude implementa.
10. Ferramentas repetem validação.

## Regra de dependências

Não instalar uma biblioteca sem:

- motivo;
- documentação;
- impacto;
- alternativa;
- tamanho;
- manutenção;
- licença;
- aprovação quando altera arquitetura.
